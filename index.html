Intervals.icu koppelen
Intervals.icu analyseert je trainingsdata en berekent je conditie. Gratis account op intervals.icu — koppel daar je Strava of Garmin.
📍 Athlete ID: intervals.icu → klik op je naam rechtsbovenin → staat in de URL als i1234567

📍 API Key: intervals.icu → Instellingen (tandwiel) → Developer Settings → kopieer de API Key
Staat in de URL als je ingelogd bent: intervals.icu/athlete/i1234567/...
Instellingen → Developer Settings → API Key (begin met "API_KEY:")

Claude API koppelen
Claude is de coach die jouw data interpreteert. Maak een account op console.anthropic.com, voeg betaalmethode toe en maak een API key aan. Kosten: ~€2-5 per maand bij normaal gebruik.
📍 API key vinden: console.anthropic.com → API Keys → Create Key
